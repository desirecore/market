# 个人笔记工作台教学示例

这是可修改的最小材料，不是正式市场条目或已经完成的真实 Agent 验收。将示例复制到任务实际授权工作目录，用本 Skill 的 create-release.mjs 生成 app-release.json，再交平台 prepare/snapshot 预览与个人发布。

笔记保存在声明的 notes key，由平台按用户/实例/预览分配专用数据根。预览数据不自动成为正式数据；包中没有 notes.json。裸浏览器打开可看到页面，缺少可信桥时不会假装已持久保存。Web 须有独立 app origin 和真实 parent MessagePort；同源或无来源时桥拒绝。

保存使用 expectedETag/expectedAbsent；结果不明保留原 mutationId 和正文，先查原回执。示例只在当前页面保留待查询 ID，完整产品应通过获授权的视图状态或自身数据合同保存可恢复的请求引用，不能持久化平台 token。

“交给 Agent”先准备提案。真正提交在平台控件上确认，再从 work-accepted 或同请求 lookup 得到真实接纳/Task 状态；页面不能自己签 intent。正式实例引用已声明notes来源文件：namespace为data-files、objectId为notes、revision为readData的真实ETag，平台不猜测notes JSON内部业务schema。选中笔记的稳定id、记录版本及可见文字留在summary；授权范围明确包含读取来源文件并仅讨论所选记录。Agent读取真实文件后定位记录，不能把未实现的notes业务对象owner说成已支持。预览只发讨论摘要，不借正式实例身份。

更新保持原安装/data scope并先核验 notes-v1兼容；程序回退不恢复旧笔记。卸载默认保留业务数据。示例无需第三方服务，调用 Agent 仍取决于真实算力连接、权限和额度。平台能力未开放或未发行时保持不可用并说明原因。
