# SAG Wiki 技能

## 范围与来源

这是上游 Agent 技能 `cli/skills/sag` 的可选 MIT 本地版。固定提交、逐文件哈希，以及把根 LICENSE 复制进本包的原因见 [UPSTREAM.md](UPSTREAM.md)。目录标识为 `sag-wiki`；上游 frontmatter 名称为 `sag`。

请自行安装并运行独立许可的 `@zleap-ai/sag` CLI。本包不含 SAG Wiki 应用本身，也不含仓库其余部分的演示视频或第三方二进制。

上游技能原文见 [references/upstream-skill.md](references/upstream-skill.md)。在 CLI 安装完成后，按其说明做配置、检索、忽略规则和 MCP。

## 前提

- 能够加载本技能的 Agent 运行环境
- 另行安装并取得许可的 `@zleap-ai/sag` CLI
- 上游技能说明中的 MCP 或目录索引配置
