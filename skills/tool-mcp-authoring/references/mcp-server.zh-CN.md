# 自编 MCP 的接入合同

适用于多个操作共享连接/状态，或需要 MCP 客户端复用的能力。服务代码由 Agent 选择语言和 SDK；以所选已安装 SDK 的真实协议和文档实现初始化、工具列表、参数 Schema 与调用，不伪造成功回执。

## 服务、依赖与目标宿主

在获准目录保存服务源、依赖清单/锁文件和配置 Schema。使用真实运行时路径；本地 stdio 程序只向 stdout 写 MCP 协议，日志写 stderr。实际启动目录和模块解析必须经过验证，不能假设 Electron 内置了作者选择的库或平台相关原生驱动。

共享状态归实际服务进程所有。多个 Agent 各自配置同一 stdio 命令通常会各自启动进程，不会自动共享串口句柄；需要共享独占设备时，按实际目标选择一个受治理的服务 owner 或明确的连接/锁设计。MCP 不保证请求天然串行，设备队列、并发与断连恢复由实现按协议需要处理；不能把挂载同一名称或目录登记当作已解决资源竞争。

明确设备连接发生在哪台 Agent Service 宿主。远端服务上的 COM/USB 不是用户浏览器所在电脑的设备。外部库、硬件和托管服务按其许可证、部署和授权条件使用，连接登记不提供这些资源；缺条件时停止受影响操作并报告。

## 接入自身 Agent

实际连接请求由当前客户端的 McpConnectionRequest/Schema 决定。通过当前获准且可用的本机 API 路径，可以先 `POST /api/mcp/test-connection`，正文 `{connection: <连接请求>}`；再 `POST /api/agents/<自身 id>/mcp-servers`，正文例如：

```json
{
  "serverId": "example-device",
  "config": {
    "transport": "stdio",
    "command": "<宿主真实 Node 可执行文件绝对路径>",
    "args": ["<已安装服务入口的绝对路径>"],
    "cwd": "<已授权服务目录的绝对路径>"
  }
}
```

尖括号是待替换的真实路径，不可原样执行。路径/args 分开传递；敏感连接值使用原连接或秘密引用能力，不把平台 token、密码写进文件或 CLI 参数。连接请求与持久化 agent.json 的 mcp_servers 结构并非相同对象；使用该接口转换，或核对真实 agent.json Schema 后用获准文件工具编辑自身配置并 `RefreshAgentFS(changeTypes=["agent"])`。`ManageAgent.update` 不接受 mcp_servers，不能把拒绝当作 MCP 不受支持。

普通 embedded 本机非治理 API、remote/standalone 和 mediated 模式的访问方式不同，以当前提示词和实际权限为准。受中介约束或入口不可用时使用已提供的原配置能力，或明确报告缺少入口；不读取平台凭据、伪造 Origin 或使用其它身份绕过。首次连接可能真实启动服务进程，仍沿原文件、执行、请求与 MCP 调用审批。

远端连接使用客户端实际接受的传输、端点和 OAuth/secretRef 合同；无需为普通自编本地 MCP 构造外部目录来源证明。已有目录托管服务则沿其原获取/安装合同，不伪造目录身份或改装别人的安装。

## 发现、复用与实际调用

检查连接测试的工具列表与诊断；它只证明握手和列表发现，不证明设备操作成功。保存后用当前工具目录/声明取得真实模型侧工具名，必要时 `LoadTools`；不按远端声明名或命名空间习惯猜调用名。固定子任务/后台工具上限不会因登记新 MCP 自动扩大；按原授权和会话状态选择后续执行。

真实调用一次获准的无副作用工具，再验证设备操作及必要的异常、断连/恢复和并发占用。共享目录需求可按目录加载服务登记 Skill；只给自身接入不需要全局目录。其它 Agent 要有自己的授权配置，目录可发现不代表已安装或获准执行。

配置持久化和业务监听存活是不同事实。MCP 连接与 stdio 子进程由当前连接 owner 管理，不等于系统启动服务；长期订阅需明确进程生命周期及事件进入 Agent 的真实入口。重启后检查配置、再次发现和真实调用，并单独核验业务重连。卸载自身配置可按原接口 `DELETE /api/agents/<自身 id>/mcp-servers/<serverId>`；同时依原运行 owner 关闭本次拥有的资源，保留用户数据，不结束共享进程。
