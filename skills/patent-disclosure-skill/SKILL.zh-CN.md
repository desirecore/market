# 专利交底技能合集

## 范围与来源

这个可选 MIT 本地包收录合集的 `skills/` 树、仓库根目录中已有的辅助脚本，以及包根目录和每个子技能中的上游 [LICENSE](LICENSE)。详见 [UPSTREAM.md](UPSTREAM.md)。

这不是法律意见，也不能替代具备资质的专利专业人员。可选 Python 工具和一个超过 1 MiB 的 vendored `mermaid.min.js` 已收录，因为技能会用到它们。

经过审阅的中英子技能摘要见 [references/child-summaries.json](references/child-summaries.json)。

| 标识 | 摘要 |
|---|---|
| `patent-application` | 申请文件：把已有交底写成权利要求书、说明书、摘要与说明书附图；规划发明母案与分案并核对原始披露。四件套须指定交底目录。内容争议写入问题清单，交付后请确认须摘要清单。已有产出上改稿则另存新时间戳目录。须显式触发。 |
| `patent-chart` | 权利要求对照表：独权拆成技术特征，逐格比对对比文件/产品/标准，附证据与强弱。用于无效对照、FTO 初筛、侵权/EoU、SEP、可专利性底稿。须点名。不出法律意见。 |
| `patent-disclosure` | 中国专利交底书：发明/实用新型/外观设计的专利点挖掘、轻量查新与成文、保护型1+N专利布局。 |
| `patent-docket` | 按发明人/工程师给的材料一趟写出交底书和申请文件；申请问题清单上的缺口最多改三轮。缺技术事实就问人，不编。触发：交底申请一起做、从零出交底和申请、一条龙、帮写交底再出申请、按清单改、会稿、案卷、/patent-docket。 |
| `patent-exam-policy` | 给交底用的政策简报：对照国知局近期口径，说明对交底写法/本稿的影响，并提示申请书式。技能进化仅为旁路，默认只改交底包，须另点名才改文件。 |
| `patent-map` | 专利地图：基于通俗解读已入库的 Obsidian 案例，点名后打开五种图。地形按 bge-small-zh 向量摊开。 |
| `patent-oa` | 审查答复辅助：审查意见问答与草稿；库薄时引导案例入库。须显式触发。 |
| `patent-reader` | 专利通俗解读：中国或海外（美欧日韩等）公开号 / PDF 成通俗笔记、图谱与 Obsidian 入库。 |
| `patent-search` | 专利著录检索：中国专利公布公告（发明人、申请人、分类号、名称、摘要；也可从单图或权利要求生成名称/摘要关键字后查询）；用户点名海外时，用 Google Patents 检索美欧日韩等海外专利。 |

## 前提

- 任何申请或法律结论仍须由专业人员审阅
