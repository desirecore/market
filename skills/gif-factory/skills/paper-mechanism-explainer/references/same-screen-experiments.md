# 同屏实验

选择此风格、延续吸管或铜管实验，或要求“相同条件、只改一处、同时看差异”时读取。它以控制条件与动态因果为主，不靠换配色定义风格。

这是本项目内置的独立制作流程，已完成吸管五秒小样、铜管五秒小样和79秒铜管完整片；本例没有调用 lemo-opuscar，也没有复用其风格文档、场景、着色器或导出工具。同屏对照是通用表达方法，独立制作的是本例的装置、模型、镜头和声音编排。外部立体剖面仍按[该分支](lemo-cutaway.md)保留上游说明。

## 选题与条件

优先选能用一个关键变量产生清楚差异的题目，先核实原理与适用条件，再写比较关系。每期保存：两边共同条件、改变的变量、预期可见结果、必要的近似和来源。

| 方向 | 可以比较什么 | 新题目先确认什么 |
| --- | --- | --- |
| 日常物理 | 吸管封口/开口、水瓶通气/密封 | 初始水量、气路、液面与密封条件 |
| 材料结构 | 平纸/折纸承受相同载荷 | 纸量、方向、跨度、支承与失效方式 |
| 机械 | 定滑轮/动滑轮、不同有效力臂 | 提升高度、绳长、输入力、接触和摩擦假设 |
| 电磁 | 完整铜管/贯通纵缝铜管 | 磁铁、管径和长度相同；导电回路与剩余阻尼 |
| 金融与商业模型 | 单利/复利、按次/包月 | 明确假定费率、周期、现金流与比较口径；模型不等于实证或收益承诺 |

目前验证集中在吸管和铜管。其余方向是选题入口，每个新题目都需自己的资料、模型和样片；不要直接套铜管参数。

## 画面与导演

以能看清材质、接口和运动的实物几何为主；已验证版本为冷灰实验桌、铜材或透明管、固定支架和克制的细线标注。没有人物或微缩人偶。其他物件按实际结构制作，不统一画成铜管或装水容器。

建立对照时用相同尺寸、视角、光照、起始状态和同一时钟；关键操作同步。先让结果发生，再解释原因。近景可跟踪运动件，也可固定观察管壁某一位置；改变观察坐标时给观众参照物。

完整片可从“同屏结果 → 关键变量的局部 → 追踪状态变化 → 回路或受力 → 能量/守恒 → 回到同屏”中选需要的镜头，不固定段数。不要把五秒小样循环拉长代替完整讲解，也不为填画面堆术语、标题卡或无关道具。

透视只改变显示；实际切缝、阀门或气路才改变模型。需要看内部时保留真实外壳与导电/密封条件，标明“前壁透视”等必要范围；不能一边展示切掉导体，一边仍按完整回路计算。磁场线、电流和力箭头是解释图形，不能伪装成可见发光物体或实测结果。

已验证起步1920×1080、24fps。主标签约34–50px，字幕约40px，底部预留区域；这只是案例起点，按画幅与阅读量调整。比较建立后可推进近景，但同屏评判的两个对象应完整可见。竖屏可以上下对照，不能把横版直接挤窄。

## 状态、时序与声音

用一份状态模型驱动位置、开关、切缝、轨迹、箭头、计数器和能量；同一时刻的实物与透视必须对应。保留按绝对时间定位的入口，例如 `render(t)`，直接定位与逆序定位应得到相同画面。

可编辑几何不等于物理仿真。简化动力学、时间放慢、场线和能量图在对应步骤或来源说明中写清；没有标定数据就不显示像实测一样精确的落时、温升或受力数值。检查与本题有关的守恒、接触和方向，而非只核对首尾。

先使用实际旁白及分句时间，再安排释放、切缝解释、路径形成和总结。字幕尽量保留完整语义，尤其否定条件，避免把“铜不会像铁一样吸住磁铁”拆成单独的“吸住磁铁”。只改画面时复用已有音轨。

五秒方向小样可以只配轻拟音；完整片沿用用户已选声线。铜管案例用了 Clipchamp 云杰 HD，详见[配音流程](clipchamp-voiceover.md)，这不强制其他用户选同一声线。背景音乐轻放并避让旁白；拟音与可见的释放、触碰同刻，场线图示不自动配电流嗡鸣。

用户只要小样时按要求交付；已经明确要求完整片时继续完成整片，不额外设一轮样片审批。

## 检查与交付

- 核对两边起态、关键操作、结果与标注：改变的是指定变量，明显的其他条件差异有解释。
- 看实际几何的孔、缝、内外表面、接触和遮挡；检查相反表面法线、共面闪烁及错误穿透，不能只看模型参数。
- 核对统一时钟、任意定位与逆序定位；必要时对同一时间的导出帧作哈希比较。
- 核对相关守恒和方向：吸管看水量，铜管看磁通变化、电流方向、阻力方向与能量去向；接触软垫后的碰撞损失不能算到铜管发热。
- 检查实际编码文件的画幅、帧率、时长、字幕、音轨与完整解码。技术测量、视觉自查和人耳试听分别记录。

工具按环境选择。铜管案例使用独立 Three.js / WebGL、可用浏览器与 FFmpeg；它不需要外部影片 Skill、生成视频模型或特定浏览器。浏览器操作按当前可用工具的说明执行，不照抄旧会话、端口或账号。

交付成片、封面、字幕、可编辑工程和来源说明；公开默认无个人水印。参考图供看构图，不能替代运动验收。
