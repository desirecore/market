# 从文章选配色

## 文章只用少数几类入口

100套颜色供选择，不需要分出100种文章。先按用途看，再叠加题材和情绪：

| 用途 | 画面先解决什么 | 颜色怎么考虑 |
| --- | --- | --- |
| 教程 | 让读者看懂要学什么、从哪里开始 | 标题层级清楚；简单教程也可以鲜明轻快，不默认全用蓝灰 |
| 工具介绍 | 看出工具解决什么问题 | 有明确重点；发布可以大胆，限制与成本说明可以克制 |
| 分析 | 看出讨论对象和关键关系 | 层次稳定；风险色只强调关键信息，不整张都做成警报 |
| 经验 | 看出当事人的处境或变化 | 跟文章落点走，离职、失败也可能是温暖的生活过渡 |
| 清单 | 看出是一组资源、方法或入口 | 有共同底色和一个强调色，避免每项各用一套颜色 |
| 故事情绪 | 让场景、留白和情绪承接文字 | 照片、暖纸或墨线可以是主角，点缀不必很多 |

热点评论先判断是调侃、质疑还是解释，再决定强度；新闻记录优先人物或事件识别度，传闻与正式消息的表述要区分。具体文章可以横跨两类，不强行归入唯一格子。

## 先看原画面能不能保留

用户给了现成封面或选好另一套风格时，先看它的主体、材料、字体、空白和用色数量。把原配色与目录候选一起比较：换色能更贴题、更清楚才换；暖纸、墨线或清晰的新闻配色原本合适，就保留原方案并说明原因。用户指定编号时仍按指定执行。

先定哪些地方可以改色，再分颜色：背景、纸面、标题、关键词底条或少量焦点。人物肤色、真实照片、产品色、截图与图例不因为套色而全图染色。材料本色与光影可以保留，四色不必均分，墨线风格不必铺满彩色。

与其他封面Skill配合时，沿用对方的主体、构图和材料要求，这里补用色方案；没有其他Skill时照常交付颜色建议，不承担封面设计。选色分数只能帮查表，不能代替这一步的设计判断。

## 先判断文章在做什么

读标题和正文，写清三句话：讲什么、最重要的结论是什么、希望读者带着什么感觉往下读。文章里的事实与情绪分开看。

- **题材**定候选范围：科技、财经、生活、旅行、饮食、文化等。题材可以有两项，不要把每个名词都列成标签。
- **表达目的**定画面的力度：解释和教程重清楚，发布重识别，叙事重气氛，纪念重克制。
- **情绪**定冷热与轻重：以作者最后要传达的态度为准。文章写到失败，落点可能是温暖；写到AI，语气也可能是冷静的分析。
- **视觉强度**用1—5表示：1安静、2克制、3鲜明、4强烈、5高能。它表示封面要多抢眼，不表示文章多重要。

判断时留一条具体内容依据，例如“正文在拆毛利变化，语气是解释而非庆祝”。只有标题时先给暂定判断，不声称读过不存在的正文。信息足够时自行推进，不让用户填设计问卷。

## 先执行明确要求，再查表

用户指定的编号、色号、品牌底色、画幅和现有素材优先。编号指定后不擅自改成得分更高的另一组。条件互相冲突时说明冲突，例如既要求保留又排除同一色号。

现有照片先看图：找原有颜色与落字空位，再挑接近的组合；用标题、衬底和小点缀承接配色。人物肤色、产品实色、截图和图表颜色按用户要求保留。金融涨跌或其他有明确定义的图例不随装饰配色重染。

这些条件无法由100组满足时，直接用自定义HEX，不把新颜色偷偷写回原100组。

## 用题材、情绪和任务一起选

从目录挑一套主推，最多两套备选。脚本参考权重：情绪35、表达目的25、题材20、视觉强度20；它执行的是助手已经做出的内容判断。

备选应能看出区别，例如浅底与深底、冷静与更鲜明。不要让001和011这种很接近的紫黄组合占满全部备选；用户要细比近似色时再一起列出。

有相同关键词的文章可以选不同颜色：

| 文章落点 | 先考虑 | 原因 |
| --- | --- | --- |
| 拆一款AI产品的成本与限制 | 065、061、100 | 冷静解释，让字和数据先被读到。 |
| 发布一款大胆、有趣的AI小工具 | 070、001、079 | 允许更强的撞色和更短的标题。 |
| 写工作倦怠后放慢生活 | 055、064、050 | 结尾若是安定与照顾自己，就按温暖或柔和选。 |
| 城市旅行中的旧街与记忆 | 026、088、060 | 看叙述更偏暖旧物还是冷黄昏。 |
| 自然观察、种植与户外笔记 | 063、080、083 | 用有层次的绿与浅底，留空间给真实图像。 |

这些是可比方向，不是必须命中的唯一答案。最终解释要连回这篇文章的一句话；不把颜色说成能保证点击或转化。

## 再把颜色分工

1. **底色**占大面积，承接文章气氛。浅底、深底都可，只用一种作主要底。
2. **标题色**先保证可读，再追求色彩冲击。表中只限大字的搭法，缩到390px宽时标题至少约28px；做不到就用正文色。
3. **正文色**给小字、注释和HEX使用。每个色块分别检查，不拿总画面的对比代替局部对比。
4. **点缀色**放关键词底条、一个小块、线条或焦点物件。小字不能因为是“强调”就放弃读字对比。

默认用至少3:1作大标题对比检查、4.5:1作小字检查。这是本模板的读字门槛。若原配色做不到，就明确补黑或白作为字色，原配色的HEX与数量不变。关键词底条、标签、角落说明分别按自己的局部底色检查；不能拿主标题在总背景上的对比代替它们。

三色封面可以从大底、次色、小点缀开始；46—60组的原清单给了6:3:1，默认按原色顺序保留这条面积建议。两色不硬加第三块，四色不要求四块一样大。窄色卡为了让色名和色号清楚，各块宽度可以均衡，不强行照用封面的面积比例。

## 给用户看的说法

用大白话交代主推编号、为什么适合这篇、底色/标题/点缀怎么分。比如：

> 主推065“冷静科技”。这篇在解释产品限制，适合克制一点。雾灰白打底，深海藏青写标题，钢蓝灰作线条和小块；大块留白给标题。

选色任务到这里完成。需要成图时，把配色方案交给Punk或其他封面工具。
