# 和Punk怎么搭配

推荐搭配[Adrian Punk的Punk-Posters](https://github.com/adrianpunk/Punk-Posters)使用。本文只说明两套工具的分工与交接，没有复制Punk的风格规范或生成提示词。

| 谁来做 | 负责什么 |
| --- | --- |
| 文章配色 | 理解文章的用途和情绪，推荐颜色，确定底色、标题、小字、点缀与保留范围 |
| Punk | 根据用户要求确定封面风格、构图、字体、主体与画幅，并用可用的画图工具成图 |

## 使用顺序

1. 先把文章交给文章配色，拿到配色建议。用户已经选好编号或品牌色时直接采用。
2. 用户要继续制作封面时，把文章、标题、素材和配色交接单交给已安装的Punk封面工作流。
3. 按Punk当前的说明确定风格和画幅，将交接单作为用色要求。原风格、材料或可用颜色数不适配时，说明冲突；用户没有指定固定配色时，保留原配色也可行。
4. 实际出图与画面检查由制作封面的一方完成。选色脚本不产生图片，不自动下载、安装或调用Punk。

## 可直接发给助手

> 先用文章配色Skill帮我选色，再用Punk制作封面。文章和标题我来提供，先保留已选风格和照片里的真实颜色。
