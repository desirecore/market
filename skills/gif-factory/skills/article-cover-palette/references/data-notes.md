# 数据说明

- 编号001—100、原配色名、颜色顺序与HEX来自用户提供的100组配色清单，保持原值。相近的001和011也保留各自编号。
- 61—79组原文没有逐个颜色命名，单色名称为方便读表补上的描述；不把这些名称说成标准色名。
- 每组的题材、情绪、视觉强度和标题/底色搭法是本次编辑建议，不是品牌官方规范、情绪测量或点击率承诺。
- `catalog.json`是唯一维护的数据源，`palette-table.md`、CSV和`color-cards.md`是其阅读版。修改时一并重新导出，不能各改各的。
- 编辑后用`scripts/export_table.py --csv <输出CSV路径> --cards <色卡图表路径>`重出表格；改了颜色时先用`scripts/palette.py`中的`color_roles`重算`default_roles`，不要保留旧的标题/底色搭法。
- `assets/cards/`的100张卡片是已完成的AI视觉预览。字面色号与清单核对过；AI色块和JPG像素不保证等于原HEX，精确配色使用目录数值。
- 原清单中的用字按原样保留，例如“米汤骄”“芡食白”；不悄悄更名或换色。
- 验证范围：目录与原清单一致、字色对比计算、脚本输入与配色交接单导出、若干模拟文章的选色试跑。它不等于为生图模型训练了新权重，也不能替代新文章的实际成图检查。
- 后续做过8组封面原配色与目录配色的本地对照，得到的经验是：保留原配色也可行，材料与构图先于机械套色，带底小字要逐处检查。这些是有限样本的设计观察，没有点击率或通用稳定性的验证。
- 本包独立提供选色说明、脚本、配色交接模板与用户这100套色卡。第三方封面Skill、风格规范、提示词和测试图不随本包分发；需要配合使用时从原作者处另行获取并遵守其许可。
