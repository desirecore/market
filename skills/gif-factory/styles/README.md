## 动态签名

先选想要的效果，再选字体、配色和动效，也可以直接提供字稿。

| 风格 | 能做什么 | 预览和做法 |
| --- | --- | --- |
| 纯文字连笔 | 沿字迹写出名字，配单色或渐变 | [打开](../skills/dynamic-art-signature/references/styles.md#word-only) |

## 电影片头

中文50种写法，英文50款基础字体和装饰封面，也支持自定义字体。中文 F41–F50 十款手写风格附原稿、长短句对照和独立场景。可以重新设计片名和场景，也可以直接用你提供的照片、文案或字稿。

[看中文50种字形](../skills/cinematic-title-lettering/references/style-catalog.md) · [十款手写字怎么用](../skills/cinematic-title-lettering/references/handwriting-stability.md) · [看做法](../skills/cinematic-title-lettering/references/film-title-frames.md) · [独立 Skill](../skills/cinematic-title-lettering/SKILL.md)

[看英文50款与五组大图](../skills/cinematic-title-lettering/references/english-titles.md)

## 文章封面配色

100套可选配色，附100张现成色卡。按文章内容与情绪推荐颜色，说明标题字、底色和点缀怎么分，不负责封面设计和出图。推荐搭配[Adrian Punk的Punk-Posters](https://github.com/adrianpunk/Punk-Posters)制作封面，分别安装并按各自许可使用。已有配色合适时可以保留。

[说明与安装](../skills/article-cover-palette/README.md) · [100张色卡＋色号](../skills/article-cover-palette/references/color-cards.md) · [用途和搭法](../skills/article-cover-palette/references/palette-table.md) · [独立 Skill](../skills/article-cover-palette/SKILL.md)

[看做法和案例](compact-storybook/STYLE.md) · [独立 Skill](../skills/compact-storybook/SKILL.md)

## vibe 知识大赏

内容分为生活机关、机械结构、物理现象与金融机制；画面风格单独选择，续作沿用当前选择。

| 风格 | 主要效果 | 完整案例 |
| --- | --- | --- |
| 摄影纸艺 | 黑纸、摄影剪贴、撕边与实际操作 | [贷款创造存款](../examples/mechanism-explainers/loan-creation/README.md) |
| 彩色贴纸风 | 奶油纸底、二维白边贴纸、物件与资金路径 | [优惠券到底谁买单](../examples/mechanism-explainers/coupon-funding/README.md) |
| 复古档案记录 | 档案夹、暖色照片、账纸、红笔与核对章 | [大包装一定更划算吗](../examples/mechanism-explainers/unit-price-archive/README.md) |
| 同屏实验 · 内置 | 相同条件并排操作，观察变量造成的差异，再用局部透视与统一模型解释 | [铜管与磁铁](../examples/mechanism-explainers/copper-magnet-same-screen/README.md) |
| 立体剖面联动 · 外部 Skill | 调用 lemo-opuscar，剖开外壳、按齿数联动、镜头追踪传动路径 | [齿轮减速原理](../examples/mechanism-explainers/gear-reduction-cutaway/README.md) |

立体剖面分支实际使用 [Lemo-Opuscar by Lemomo（LemoLab）](https://github.com/lemomo-ai/lemo-opuscar) 的 Skill 与部分渲染代码；本仓库提供入口和案例，所需上游 Skill 与运行时另行安装。
