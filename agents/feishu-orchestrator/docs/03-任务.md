# 任务

**对助手说**：「我还有哪些没做完的」「把这件事记成待办，下周五截止」

**实测命令**：

```bash
lark-cli task +get-my-tasks --as user --complete=false --page-all --format json
```

**要点**：
- **`--complete=false` 不能省**。不带它会**同时返回已完成和未完成任务**，站会摘要、待办清单这类场景会混入大量已完成项。
- 操作任务用的 `guid` 是全局唯一标识，**不是**客户端界面上显示的任务编号（`t104121` 那种）。
