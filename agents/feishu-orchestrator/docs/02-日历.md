# 日历

**对助手说**：「我今天有什么会」「下周二下午三点约个项目评审，叫上张三」「这周谁有空开会」

**实测命令**：

```bash
lark-cli calendar +agenda --as user \
  --start '2026-09-01T00:00:00+08:00' --end '2026-09-01T23:59:59+08:00'
```

**要点**：
- 时间**必须带显式时区偏移**。容器默认时区常为 UTC，不写偏移会产生 8 小时错位——这是官方文档用「违者将导致严重的逻辑错误」措辞标注的。
- `--start` / `--end` 只接受 ISO 8601 或 Unix 时间戳，**不认** `"tomorrow"`、`"next monday"` 这类自然语言。助手会自己换算成绝对时间。
- 查会议室要先确定时间块，模糊时间需先走时段推荐。
